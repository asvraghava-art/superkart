
# SuperKart Sales Forecasting

This project predicts Product Store Sales using Machine Learning.

## Models Used

- Random Forest Regressor
- XGBoost Regressor

## Final Model

Random Forest Regressor

## Performance

- R²: 0.9311
- RMSE: 280.41
- MAE: 77.86
- MAPE: 2.96%

## Deployment

- Backend: Flask API
- Frontend: Streamlit
- Containerization: Docker
- Hosting: GitHub Codespaces
